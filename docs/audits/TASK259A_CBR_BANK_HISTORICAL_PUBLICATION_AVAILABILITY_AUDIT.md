  Permanent HTTP failures are not retried.

  no more than 12 alternative sources (eleven in the final run).

  `application/rar`, zero redirects and final URL identical to source URL.
  This proves an observable response, not the integrity of unconsumed bytes.
- Header values are preserved raw as well as normalized. HTTP Date is message
  time; Last-Modified is representation metadata. No artifact content hash is
  derived from Content-Length or ETag.

## F. Weak-evidence warnings and classification

```text
REPORT_DATE != PUBLICATION_DATE
CURRENTLY_OBSERVABLE != HISTORICALLY_AVAILABLE
METADATA_TIMESTAMP != PROVEN_PUBLICATION_TIMESTAMP
```

Report dates, filename dates, DBF/member timestamps, discovered/retrieved/ingested
times, HTTP Date, ETag, and current catalog presence never populate
`explicit_publication_at`. Page update dates do not propagate to all links.

Example: the 101 artifact for 2023-07-01 returned Last-Modified
`Thu, 30 Nov 2023 06:59:03 GMT`, not its report date. The 135 artifact for
2026-08-01 returned `Wed, 26 Aug 2026 09:05:00 GMT`. Neither value identifies
first historical release or proves equivalence with persisted production bytes.

The implementation separates the eight source-evidence types from the six PIT
classes requested in Task259A. Its pure reviewed-assertion classifier permits
PROVEN_EXACT/PROVEN_DATE_ONLY only with an official source/semantics URL,
documented semantics, explicit artifact matching and proven immutable-version
binding. Date-only stays a date. Synthetic positive tests are **not live evidence**.
The live adapter supplies no reviewed publication assertions because no such
exact-version contract was established. Last-Modified alone does not produce
even POTENTIAL_CONSERVATIVE_BOUND in this audit.

Provenance verdict: official metadata present; historical-publication claim
unverified; no controlled values, publication writes, backtests or PIT promotion
allowed. Financial metric/unit/manual-value review fields are not applicable:
Task259A does not process financial values.
